# DevMind 是什么（小白版）

## 一句话

DevMind 是一个「先查你上传的资料，再回答问题」的 AI 系统。

它不会凭空猜答案，而是先在你上传的技术文档里找到相关内容，再让大模型根据这些内容回答，并且告诉你答案来自哪份文档。

## 它能做什么

1. 上传 Markdown 或 PDF 技术文档；
2. 系统自动把文档拆成很多小块；
3. 每个小块被转成一组数字，也就是向量；
4. 你提出一个问题；
5. 系统找到和问题最接近的几个小块；
6. 大模型只根据这几个小块回答；
7. 返回答案，同时返回引用来源。

## 为什么不能直接把文档丢给 AI

大模型平时学的是公开知识，它不认识你公司的私有文档。

如果每次把整本文档都发给 AI：

- 文档太长，费用高；
- 回答速度慢；
- 很多无关内容会干扰答案。

所以 DevMind 先做“检索”，再让 AI “阅读”。这个方式有一个专业名字：**RAG**。

## 一个生活比喻

把 DevMind 想象成一个图书馆管理员：

- 你把书放进图书馆；
- 管理员先给每本书做索引；
- 你提问时，管理员先去书架找到最相关的几页；
- 再把这几页拿给一个聪明的读书人看；
- 读书人根据这几页回答你。

回答错了，至少还能翻回去看是哪一页写的。

## 现在做到哪一步了

目前完成的是可运行的 MVP（最小可用版本）：

- 知识库管理；
- Markdown/PDF 上传；
- 文档切块和向量化；
- 相似内容检索；
- RAG 问答；
- 引用来源；
- 会话消息记录；
- 重复文档识别；
- 文档删除；
- 统一错误提示。
