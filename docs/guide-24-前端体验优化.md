# DevMind 前端体验优化（阶段 T）

## 背景

阶段 T 是第二轮计划的最后一个阶段，目标提升使用体验：问答打字机效果、深色模式、移动端适配。

## 功能与实现

### 1. 问答打字机效果

- `ChatView` 新增 `typeAnswer(text)`：回答返回后按 16ms/帧、每帧 2 字符逐字渲染到 `displayedAnswer`；
- 新提问触发打字机；切换历史会话直接完整展示（不打字）；离开页面/新建会话时清理定时器；
- 模板回答区改用 `displayedAnswer`。

### 2. 深色模式

- `main.css` 增加 `[data-theme="dark"]` 覆盖全部 CSS 变量（背景/面板/边框/文字/强调色等）；
- 硬编码的 `#fff`（按钮、输入框）、`#fafcfd`（表头、回答区）变量化为 `--input-bg` / `--alt-bg`，明暗主题共用；
- 顶栏新增「深色/浅色」切换按钮，切换时设置 `document.documentElement.dataset.theme` 并写入 `localStorage`（`devmind_theme`），刷新后保持。

### 3. 移动端适配

- `main.css` 新增 `700px` 断点：`main` 内边距、面板内边距、表格单元格紧凑化，面板头/操作区自动换行；
- 顶栏：`700px` 以下导航横向滚动（`overflow-x: auto`），标签不换行；
- 各页面已有的 `900px` 单列断点保持。

## 验证结果

| 项 | 实测 |
| --- | --- |
| 打字机效果 | 回答区字符数采样 `[26, 52, 78, 106]` 递增，逐字显示生效 |
| 深色模式 | `data-theme=dark`，body 背景 `rgb(19,23,28)`、面板 `rgb(29,36,44)`、文字 `rgb(217,224,232)`；按钮切换与刷新持久化正常 |
| 移动端 | 700px 断点样式编译通过，导航横向滚动 |
| 回归 | 前端 21/21 测试、部署 health=UP，问答/知识库页面正常 |

## 说明

- 打字机为前端逐字动画（基于完整回答），未改造后端为真正 SSE 流式——在模型 429 限流环境下，真实流式链路更脆弱且收益有限；如需真流式可后续在模型网关支持 `stream=true` 时再加。
