# 运维与容量专题

## PostgreSQL 怎么建向量索引

在 PostgreSQL 中使用 pgvector 插件：先 `CREATE EXTENSION vector`，向量列用 `vector(N)` 类型，再建立 HNSW 索引加速相似度检索，例如 `CREATE INDEX ... USING hnsw (embedding vector_cosine_ops)`。HNSW 索引适合大规模向量近似最近邻检索，召回快且精度高。

## pgvector 支持哪些索引

pgvector 支持两类索引：IVFFlat（倒排文件，构建快、适合中等规模）和 HNSW（分层可导航小世界，精度更高、适合大规模）。两种都支持 `vector_l2_ops`、`vector_ip_ops`、`vector_cosine_ops` 等操作符类，按距离度量选择。

## 数据库备份怎么恢复

PostgreSQL 可用 `pg_dump` 导出逻辑备份：`pg_dump -U user -d dbname > backup.dump`，恢复用 `psql -U user -d dbname < backup.dump` 或 `pg_restore`。生产环境建议定时备份并保留多天，恢复前先验证备份文件完整性，恢复演练应定期执行。

## 日志文件怎么按天切割

应用日志按天切割由日志框架的滚动策略实现（如 Logback TimeBasedRollingPolicy）：当天写入 `app.log`，到点滚动为 `app.2026-08-04.log`，并设置保留天数（如 7 天）自动清理旧日志。运维上可配合日志目录挂载持久化，便于集中查看与归档。

## 服务异常退出怎么自动重启

容器服务设置重启策略可自动拉起异常退出的进程：`restart: unless-stopped` 会在守护进程重启或进程崩溃时自动恢复容器。应用侧还可配合健康检查（health check）与探针，在依赖（如数据库）恢复后自动重连自愈。

## Nginx 反代怎么配 HTTPS

Nginx 反向代理配置 HTTPS：监听 443，配置 `ssl_certificate` 与 `ssl_certificate_key`，将请求转发到后端应用端口。生产建议启用 HTTP/2、配置 `HSTS`、限制上传大小，并用 `location /` 代理到应用服务。

## 监控指标看哪些

核心监控指标包括：请求量（QPS）、接口延迟（P95/P99）、错误率（4xx/5xx）、模型调用成功率与限流次数（429）、Token 用量与费用、数据库连接池使用率、磁盘与内存占用。配合 Prometheus 采集与告警规则，在异常时及时通知。

## 数据库连接池满了怎么办

连接池占满通常由慢查询、长事务或连接泄漏引起。排查思路：查看 `pg_stat_activity` 找出长期占用连接的会话，定位慢查询并优化；调整连接池上限（如 HikariCP `maximum-pool-size`）与超时参数；修复未释放连接的代码路径。恢复后应观察连接数是否回落。

## 容器重启策略怎么配置

Docker Compose 中为服务配置 `restart: unless-stopped`：容器异常退出自动重启，手动 stop 则保持停止。可选策略还有 `always`（始终重启）和 `on-failure`（仅在非零退出码时重启）。生产常用 `unless-stopped` 兼顾自动恢复与人工控制。

## 生产环境数据怎么备份

生产数据备份要点：备份数据库与文件数据（上传文件目录）一并备份；使用定时任务（cron）生成带日期的备份文件并保留滚动周期（如 7 天）；备份存储到独立位置（另一磁盘/对象存储）；定期做恢复演练，确保备份可用而非"只有文件没有验证"。
